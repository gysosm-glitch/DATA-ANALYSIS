# 청주시 공공자전거 대여소 입지 분석

AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전 · 충북대학교 팀

대전 공영자전거 '타슈'의 대여소별 이용 데이터로 수요 모델(랜덤포레스트)을 학습하고, 이를 청주시 500m 격자에 적용해 **수요는 있지만 버스 접근성이 낮은 지역**을 중심으로 공공자전거 대여소 입지를 제안합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `1_전처리.ipynb` | 원본 데이터 → 대전 학습 표, 청주 예측 표 |
| `2_분석_시각화.ipynb` | 교통 공백 진단, 수요 모델 학습·검증, 청주 잠재 수요 예측, 입지 선정, 효과 추정 |
| `data/시설좌표.csv` | 청주·대전 산업단지·대학·철도역 45곳 좌표 (직접 구축, 지오코딩 검증) |
| `results/` | 분석 결과 그림(PNG)과 표(CSV) |

## 실행 방법

1. 아래 원본 데이터를 내려받아 Google Drive `내 드라이브/데이터` 폴더에 넣습니다. (`data/시설좌표.csv`도 함께)
2. Google Colab에서 `1_전처리.ipynb`를 위에서부터 실행합니다. 행정동 경계는 노트북이 자동으로 내려받습니다.
3. 이어서 `2_분석_시각화.ipynb`를 실행하면 `데이터/03_결과/`에 그림과 표가 저장됩니다.
